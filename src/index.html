bentoo kernel panic report

Your computer stopped because the Linux kernel hit an error it could not recover from (a kernel panic). The QR code on the panic screen carries the last kernel messages; they are shown below.

The data travels in the part of the address after #, which your browser never sends to any server. It is decoded on this device only.

Reporting it

  1. Copy the report above.
  2. Open an issue at github.com/obentoo/bentoo/issues, paste the report and say what the machine was doing when it stopped.
  3. If the report names a driver or module (lines after Modules linked in:), include the package that installed it.
